# 0.0.2 S2 CSS 需求登记

本文件登记各功能区视图需要、但尚未落入共享样式表（`workbench.css` / 壳层 views）的 class 与用途。若样式已在功能区自带 CSS 字符串中实现，此处仅作登记备查。

## H-19 备份目标配置（`hc.client.backup.view` 内联 CSS 已实现）

以下 class 已在 `src/hc/client/backup/view.cljc` 的 `backup-css` 字符串末尾追加，无需再落地到共享样式表；若后续迁移到 `workbench.css`，按此清单搬运：

| class | 用途 |
| --- | --- |
| `.hc-backup-target-row-actions` | 目标行内「编辑」「删除」按钮组（inline-flex，间距 .35rem） |
| `.hc-backup-target-delete` | 删除确认条容器（虚线 danger 边框、flex 布局） |
| `.hc-backup-target-delete__actions` | 确认条内按钮组 |
| `.hc-backup-target-editor` | 目标编辑器 panel（复用 `.hc-backup-panel`） |
| `.hc-backup-target-editor__grid` | 编辑器字段栅格（auto-fit minmax 16rem） |
| `.hc-backup-select` | select 控件样式（与 `.hc-backup-input` 同规格） |
| `.hc-backup-target-test` | 测试结果条基样式（muted 左边框） |
| `.hc-backup-target-test--ok` | 测试成功（positive 左边框 + 浅色底） |
| `.hc-backup-target-test--failed` | 测试失败（danger 左边框 + 浅色底 + danger 文字） |
| `.hc-backup-target-test--pending` | 测试进行中（accent 左边框 + 浅色底） |
| `.hc-backup-button:disabled` | 所有备份按钮禁用态（opacity .55 + not-allowed） |

复用既有 class：`.hc-backup-field` / `.hc-backup-field__label` / `.hc-backup-field__hint`（字段 label+控件+提示）、`.hc-backup-input`（文本/密码输入）、`.hc-backup-button` + `--primary` / `--quiet` / `--danger` 变体、`.hc-backup-actions`（按钮行）、`.hc-backup-muted` / `.hc-backup-note`（辅助说明）。

| class / 选择器 | 用途 | 期望 |
| --- | --- | --- |
| `.hc-mat-bind` | 世界书/卡片绑定行（assistant/prompt/scope 绑定信息） | 绑定关系以行内列表或 chip 呈现；key 与值之间保留可辨识间距；多条绑定纵向堆叠或横向换行，窄屏不溢出 |
